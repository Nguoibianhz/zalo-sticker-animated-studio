# Security and account privacy

This app runs on loopback, handles a personal Zalo session in process memory, and uses an unofficial library. Do not expose the server through a public tunnel or bind it to a public interface without designing authentication and access controls first.

Never post Zalo cookies, QR codes, tokens, session files, personal video, chat databases or crash dumps in GitHub issues. For a security concern, first contact the maintainer through the channels listed on https://github.com/Nguoibianhz and request a private reporting channel. Do not publish exploit details or private user data before a private channel is established.

Use the QR flow yourself. The app only reacts to exact commands sent by the logged-in account and only for stickers explicitly armed in the UI. Disconnect when finished. The project cannot guarantee continued compatibility or account safety with an unofficial API.
