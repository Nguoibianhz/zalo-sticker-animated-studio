# Contributing

Issues and pull requests are welcome. Read [LICENSE](LICENSE), [NOTICE](NOTICE) and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) first. Contributions to original application code are offered under the same PolyForm Noncommercial terms; contributions to vendored MIT code retain MIT terms. Only contribute material you have the right to contribute.

Run `npm run setup` and `npm test`. Keep QR login, session secrets and all uploaded media out of commits. Use generated test video for reproducible bugs; do not attach private chats, cookies, tokens or crash memory dumps. Preserve attribution and mark substantial behavior changes in the PR description.

Report bugs with Node/OS versions, the action that failed, and sanitized error text. For sticker compatibility, distinguish rendering, animation, forwarding and PC recents; an API success is not proof that all four work.
